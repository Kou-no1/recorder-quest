# リコーダークエスト

小学校３〜６年生向け、AULOS ソプラノリコーダー 702B(G)（ジャーマン式）を想定した学習サイト。GitHub Pagesで動く静的サイトです。NodeやAPIキー、外部サービスへのログインは実行に不要です。

2026-10-03の練習画面改善は [今回の確認記録](docs/REVIEW_2026-10-03.md)、復元・公開と従来の残件は [2026-09-27の確認記録](docs/REVIEW_2026-09-27.md) を参照してください。

## 収録機能

- 12エリア・96課題・288の小ステップ。姿勢と息から、運指、リズム、曲、サミング、表現、合奏、創作、発展演奏まで。
- 「曲のひろば」は8レベル×5曲の40曲チャレンジ。教育芸術社の教材曲と学校提供の『みんなのうた』目次にある定番曲を、運指・音域・合奏技能の段階に沿って配置。
- 40曲候補のうち21曲に学習用単旋律と電子音を収録（抜粋を含む）。残る19曲の旋律は未実装で「楽譜の準備中」と表示。追加コレクション「季節のうた」は5曲（かたつむり・雪・もみじ・ふるさと・春が来た）。楽譜付きの学習曲は計26曲です。別枠の自由練習は創作・伝承曲12曲です。教科書や歌集の掲載版との一致を保証するものではありません。
- 追加5曲はいつでも選べ、6手順・スタンプ・1曲最大15ポイントに対応。既存40曲のレベル解放条件や学習記録は維持します。
- 「曲のひろば」は、開放済みの収録曲・季節のうた・自由練習から選べる入口が初期表示。「ソ・ラ・シだけ」「短い曲（32拍まで）」「高いド以上あり」で実際の旋律を絞り込めます。レベル順の一覧にも切り替えられます。
- 「大きな楽譜で練習する」は2小節ずつ表示。前後のページ移動、再生に合わせたページ追従、次の音への指の動きを表示します。表示中の2小節か、選んだ練習範囲を通すかを選べます。二重奏の両パートも表示します。
- 「お手本→自分」は、カウント・お手本・カウント・自分の演奏時間を1〜3回交代。自分の番では旋律を再生せず、拍の音は選択式です。停止・画面移動・速度やモードの変更で、予約した音と画面の進行を取り消します。
- 収録曲ごとに、使う音・音域・学年目安・前提課題・6手順・探究の問い・出典を表示。「茶色の小びん」は冒頭8小節の抜粋です。採用範囲と確認状況は [旋律の実装・確認記録](docs/REVIEW_2026-09-26.md) を参照。
- 2拍→4拍→2小節→収録部分を通す練習。2/4の曲は「4拍（2小節）」に統合。苦手な指を1音2拍で練習するモード、弱起のカウント、付点8分音符、半音の臨時記号、小節をまたぐタイに対応。
- 6手順を試し「収録部分を通す」を選ぶと、達成スタンプを自己評価で記録。1曲最大15ポイント。各レベルの収録曲を3曲（3曲未満なら全収録曲）達成すると次へ進めます。旋律未収録の曲は新しい演奏スタンプの対象外。先生は端末ごとに全候補を開けます。
- 楽譜の「全体を画面に合わせる」、25〜150%を基本とした手動倍率、100%復帰。自動調整は長い楽譜に合わせ25%未満にも縮小します。ブラウザ自体の倍率ではなく、楽譜の表示領域を拡大・縮小します。速度40〜140、音名表示、くり返し、拍の音、輪唱。
- 低いド〜最高音のレの27音をアウロスの公開ドイツ式表（販売店転載）と照合。二重穴の片穴閉鎖、裏穴の小さなすきまを区別。最高音域のド♯は別資料と裏穴指定が異なり、機種付属表の確認が必要。702B(G)実機の音程測定は未実施。
- 自己評価による次の課題提案。苦手を報告したら前提課題へ戻り、全課題を自由に選べます。
- 各課題の最高到達分で最大30ポイント。重複加算・ランキングなし。100ポイントでレベルアップ。
- 32音までの作曲、研究ノート、スタンプ、端末保存、JSONバックアップと復元。
- ノートPC型タブレットを想定したレスポンシブUI。タッチ・キーボード操作、ダイアログ、低減モーションに対応。

## GitHub Pagesで公開

1. GitHubに空のリポジトリを作成、または保存先リポジトリを決めます。
2. 本プロジェクトの `dist/`、`.github/`、README、検証スクリプトをmainブランチへ配置します。
3. リポジトリの Settings → Pages → Build and deployment → Source で **GitHub Actions** を選びます。
4. 同梱の `.github/workflows/pages.yml` が `dist/` を公開します。手動実行もできます。
5. 実際の学習用URLを開き、学校端末の音量・保存制限・アクセス制限を確認してください。

URLは相対参照のため、`https://USERNAME.github.io/REPOSITORY/` のサブパスに対応。画面遷移はハッシュを使うためリロード時の404も避けられます。

`.openai/hosting.json` は別途作成した確認用サイトの識別情報です。GitHub Pagesでの実行には不要です。

## ローカルで使う

`dist` をHTTPサーバーで配信します。例えば `python -m http.server 8000 --directory dist`。
ESモジュールを使うため `index.html` をファイルとして直接開く方法は非対応です。

## ファイル

- `dist/index.html`: 入口

- `dist/melodies.js`: 26曲の採用旋律・拍子・弱起・出典・学習内容
- `dist/fingering-data.js`: 全27音の運指と資料間の相違
- `dist/song-review.js`: 未収録19曲の個別確認結果
- `dist/score-utils.js`: 小節分割、部分練習、タイ、倍率計算
- `dist/song-discovery.js`: 収録曲の絞り込みと開放状況
- `dist/practice-session.js`: 交代練習の時間割と2小節単位のページ分割
- `dist/practice-ui.js`: 大きな練習画面と指の動きの案内
- `dist/core.js`: 学習記録と推薦・復元検証
- `dist/style.css`: デザイン・レスポンシブ・印刷
- `.github/workflows/pages.yml`: GitHub Pages公開
- `verify.mjs`: 教材整合性・記録・復元の検証
- `melody-tests.mjs`: 音域・総拍数・拍子・弱起・部分練習の回帰検証
- `ui-smoke.mjs`: 模擬DOM・模擬Web Audioによる操作検証
- `browser-tests.mjs`: Playwrightが利用可能な環境での実Chromium検証（本番依存なし）
- `song-discovery-tests.mjs` / `practice-session-tests.mjs`: 曲の絞り込み、交代練習、弱起・タイ・ページ境界の検証
- `practice-browser-tests.mjs`: 新しい練習画面と交代練習の実Chromium検証（本番依存なし）
- `docs/REVIEW_2026-09-26.md`: 収録状況、採用版、参照先と確認の限界

基礎教材の追加は `content.js` の LESSONS / SONGS、40曲候補の情報は `song-library.js`、実際の旋律は `melodies.js` を編集します。後者に採用版と音列がある曲だけが演奏可能になります。音データは `C5:2 D5 F#5:0.75 E5:0.25 R:2` のように、実音名と拍数で記述（省略時１拍、四分音符を1拍）。C5は実音C5、楽譜上はC4です。リコーダー譜のオクターブ移調を反映します。`meter` は2/4・3/4・4/4の分子、`pickup` は冒頭の弱起の拍数です。

## 授業導入にあたって

本版は40曲すべての旋律収録が完了した版ではありません。運指図と自己評価の流れを先生の実演で照合してから児童に配布してください。譜面描画は学習用の簡易記譜です。小節をまたぐ同じ音は分割してタイで表示し、電子音は元の音価を維持します。スラー・連桁・強弱記号・フェルマータは再現していません。

学習記録はlocalStorageで端末・ブラウザ内にのみ保存。児童名を収集しません。自動同期、クラス一覧、ログイン、録音、マイクによる自動採点は実装していません。共用端末はブラウザのプロフィールを分ける等の運用が必要です。削除前にバックアップしてください。

音源はWeb Audioの電子音であり、リコーダーの息づかいや音色を再現する録音ではありません。実演・聴き合いを組み合わせてください。

「演奏家へのステージ」は継続学習への発展課題で、プロの技能認定ではありません。半音、超高音、替え指、様式に応じた装飾には機種と専門指導への依存があります。

## 検証

`node verify.mjs`

`node melody-tests.mjs`

`node song-discovery-tests.mjs`

`node practice-session-tests.mjs`

`node ui-smoke.mjs`

教材IDと前提課題、40曲の件数・配分と追加5曲の記録・復元、26曲の音域・総拍数・拍子・弱起、音符分割とタイ、全部分練習の長さ、段階解放、ポイント重複防止、推薦、旧版を含むバックアップ往復、破損データの拒否を検証します。UIスモークテストは模擬DOMと模擬Web Audioを使用し、6手順の保存、部分練習中の達成制限、未収録曲の表示、倍率計算、弱起の音高・開始時刻・停止を検証します。

2026-09-27に実Chromiumの1366×768と1280×800で表示・操作を検証しました。長い楽譜の全体表示、サイズ変更、キーボード操作、JSONのダウンロード・復元、旧記録の復元、二重奏の部分再生・停止も確認済みです。Web Audioは実エンジンの発音時刻と非ゼロの音声サンプルを確認しました。スピーカーからの試聴、学校端末、702B(G)実機の運指・音程、専門家による楽譜校正は未実施です。WebMCPは対応ブラウザでのみ読み取りと課題表示を登録します。対応実行環境での検証は未実施です。
