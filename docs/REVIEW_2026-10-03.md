# 練習画面と曲の入口の改善

確認日：2026-10-03。

## 実装範囲

- 曲の入口を「今練習できる曲」に変更。開放済みの収録曲、常時利用できる季節5曲と自由練習12曲を並べる。初期状態では18曲、先生の全曲開放時は38曲。準備中の候補は従来のレベル順一覧で確認できる。
- 絞り込みは表示用の音域説明ではなく、実際の両パートの音列を使う。「ソ・ラ・シだけ」は自然音G5/A5/B5、「短い曲」は休符込み32拍以内、「高いド以上」は実音C6以上を含む曲。
- 大きな練習画面では2小節ごとにページを分ける。弱起を含む先頭ページは「弱起〜1小節」と表示。長い音がページをまたぐ場合も、元の音符番号とタイを維持する。
- 表示中のページの反復と、選択範囲全体の再生を選べる。全体再生ではお手本の番・自分の番の両方でページが追従する。
- 交代練習はカウント→お手本→カウント→自分の順に1〜3回。自分の番の旋律は無音で、必要なら拍の音だけ再生する。各カウント開始時に先頭のページと運指を準備する。
- 次の音に移る際に動かす指を案内する。音符選択やページ移動でも図と案内を更新する。二重穴・裏穴の小さなすきまは既存の運指データを使用する。
- 停止、画面移動、速度・モード変更、タブが隠れたとき、ページ終了時は予約済みの音と画面更新を取り消す。

## 記録と既存教材

曲・課題のID、ポイント、6手順、レベル開放条件、バックアップ形式は従来のまま。練習画面を使っただけで達成スタンプを記録しない。自己評価は曲の画面へ戻り、従来の条件に沿って記録する。

新しい教材・実演録音・マイク入力・自動採点は追加していない。お手本は従来の電子音で、実際の演奏の音色や息づかいの評価は先生との確認が必要。

## 検証

公開時の必須チェックに、曲の絞り込みと交代練習の2テストを追加し、計5本とした。

- 教材・旋律・保存・復元を含む従来の整合性検証。
- 開放条件、季節曲、自由練習、絞り込みの拍数・音域、入力データを変更しないこと。
- 2/4・3/4・4/4、弱起、休符、長い音とタイ、交代回数、ページ境界。
- 模擬DOM・Web Audioで、交代の進行、自分の番に旋律を予約しないこと、停止・画面移動後に予約が再開しないこと、二重奏、学習記録の保持。
- 実Chromiumによる従来の26曲、表示倍率、バックアップと旧記録、キーボード、二重奏の回帰確認。
- 新しい画面は `practice-browser-tests.mjs` で実Chromium検証を実施し、通過。1366×768と1280×800で2小節を大きく表示し、操作ボタンが画面内に収まることを確認。二重奏の両パートも確認した。
- 速度140で実際に「自分で吹こう」へ切り替わること、予約済みの旋律が自分の番に入らないこと、停止後に画面更新が再開しないことを確認。スピーカーからの試聴、学校端末、実楽器による演奏確認は未実施。
